## Folio

- A simple GUI that uses Microsoft's markitdown (https://github.com/microsoft/markitdown) to mark-down PDF and Word files.  
- I also added an option to mark-up md files to PDF files.  
- Upon start, the app checks for Python and downloads necessary packages.
